# UI Guidelines

FollowUpGC is an operational pastoral tool. The UI should feel calm, compact,
and useful for repeated weekly work.

## Visual Direction

- Prefer dense but readable panels over marketing layouts.
- Keep cards and panels at modest radius.
- Use restrained color. Current emphasis is emerald over neutral stone/slate.
- Use lucide-react icons for section labels and action buttons.
- Keep text practical and pastoral, not corporate.

## Interaction Patterns

- Forms should be short and close to the list they affect.
- Selection should remain obvious for the current member and current session.
- Cancelled sessions should be visible in chronology but should not show
  attendance controls.
- Empty states should tell the user the next concrete action.

## Responsive Checks

For UI changes, check:

- Mobile width: no text overlap, forms stack cleanly, controls remain tappable.
- Desktop width: panels scan well and metrics do not wrap awkwardly.
- Keyboard: form fields and buttons can be reached in logical order.

## Copy Rules

- Use Spanish UI copy consistent with the existing app.
- Prefer words already used in the domain: personas, reuniones, asistencia,
  bitacora, cuidado, oracion, fecha no realizada.
- Avoid sales language, analytics language, and enterprise vocabulary.
